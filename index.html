NANUCLOUD

Instruções de Inicialização da Aplicação

O NANUCLOUD é uma aplicação web autônoma (React + TypeScript). Os navegadores bloqueiam módulos locais quando abertos diretamente com duplo clique (file://).

Como Iniciar em 2 Passos:

Opção 1: Terminal / Linha de Comandos
npm install
npm run dev
Depois aceda no navegador a: http://localhost:3000
Sistema Autônomo Acesso Livre Imediato
